## 2. Closure Strategy for 414 Unverified + 143 Partial Historical Requirements

No historical status transfers automatically to `Planaday-Native`. Every single one of the 652 requirements starts at `SPECIFIED` (or `NOT_APPLICABLE_APPROVED` strictly where superseded by O-004 / native platform scope) and advances only through executed Kotlin tests:

1. **Contract Layer (`core:*`):** Pure deterministic domain/math/recurrence/scheduler/spreadsheet/lab/interchange/security tests covering every calculation, rule, edge case, and error condition.
2. **Persistence & Sync Layer (`core:persistence`, `core:sync-client`, `server:*`):** Real Bundled SQLite + Ktor HTTP + PostgreSQL/SQLite server tests verifying all 88 typed record families, fresh DB initialization, future v1→v2 migrations, 2-client sync, conflict policies, SHA-256 blobs, and staged backup/restore.
3. **Cross-Feature Integration Layer (`tests:integration`):** All 15 mandatory end-to-end journeys (`INT-001`..`INT-015`) proving single canonical UUID reuse and permission enforcement across workspaces.
4. **Native UI & Accessibility Layer (`apps:android`, `apps:desktop`):** Real Compose UI tests for Android compact (320dp) + tablet layouts and Windows Desktop multi-pane keyboard/mouse workflows.
5. **Independent Verification Gate:** Separate reviewer audits test results, code provenance, packaged binaries, and physical Android hardware before changing status from `DEVELOPER_TESTED` to `INDEPENDENTLY_ACCEPTED`.
