## 2. Active Blockers & Remaining Risks

1. **Docker Daemon Offline Locally:** `docker compose --env-file deployment/.env.example -f deployment/docker-compose.yml config --quiet` passed (exit `0`), but live PostgreSQL 17 container execution & restore drill requires starting Docker Desktop.
2. **Android Emulator & Physical Hardware (`C-0055`, `PF-37`, `PF-53`, `N-010`, `N-015`):** Debug APK (`android-debug.apk`, API 36, `minSdk 29`) builds cleanly, but interactive emulator / physical Android 10 & Android 16 testing (Gboard IME composition, TalkBack, Doze alarm reboot recovery, camera/photo picker, Android Glance AppWidget) remains environment-blocked pending device/emulator availability.
3. **Windows MSI Signing & Clean-VM Install/Uninstall Check:** Native `Planaday Native-1.0.0.msi` and `Planaday Native.exe` built cleanly via JDK 21 `jpackage` + WiX, but Authenticode code signing and clean Windows VM install/upgrade/uninstall smoke testing await owner signing keys and test VM.
4. **Remaining Secondary Visual Polish:** While all 54 named workspaces (`C-0001`..`C-0054`) have live Compose UIs wired to Room SQLite + FTS5 + Canvas visualizations (function grapher, Wet vs. NIR scatter plot, whiteboard vector canvas, analog clock, 260 stickers, 50-state map), remaining fine-grained tactile interactions (pointer drag-resize on minute gridlines, full stylus pressure inking, visual slide drag canvas, multi-column virtualized spreadsheet grid) correspond to the remaining `283` `SPECIFIED` requirements and are clearly itemized in `docs/REQUIREMENT_TRACEABILITY.csv`.
5. **Independent Second-Party Review:** Required before changing any gate or requirement from `DEVELOPER_TESTED` to `INDEPENDENTLY_ACCEPTED`.
